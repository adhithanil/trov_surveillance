# 🤖 Robot Vision System – Real-Time Object Detection

Real-time object detection for industrial robot surveillance cameras.
Detects people, vehicles, equipment, and obstacles using the **Roboflow** inference API,
overlaying annotated bounding boxes on a live video stream at 30 FPS.

---

## Quick Start

### 1. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 2. Configure your API key

Edit `.env` and set your Roboflow API key:

```
ROBOFLOW_API_KEY=your_api_key_here
```

Get a **free** API key at [https://roboflow.com](https://roboflow.com).

### 3. Run the system

```bash
python final_live_detection.py
```

A live video window will open. Detection boxes appear within 0.5 seconds.

## Configuration (`.env`)

| Variable | Default | Description |
|----------|---------|-------------|
| `ROBOFLOW_API_KEY` | *(required)* | Your Roboflow API key |
| `MODEL_ID` | `coco/17` | Model slug (`workspace/project/version`) |
| `CONFIDENCE_THRESHOLD` | `0.5` | Minimum confidence to show a box (0–1) |
| `DETECTION_INTERVAL` | `0.5` | Seconds between API calls |
| `CAMERA_SOURCE` | `0` | `0`=webcam, RTSP URL, or video file path |

### Example: RTSP camera

```
CAMERA_SOURCE=rtsp://admin:password@192.168.1.64/stream1
```

### Example: Video file (for testing without a camera)

```
CAMERA_SOURCE=test_video.mp4
```

## Features

- **Smooth 30 FPS display** – API calls run in background threads; the video loop never blocks.
- **Colour-coded bounding boxes**
  - 🟢 **Green** – People / workers (safety priority)
  - 🔴 **Red** – Vehicles (forklifts, trucks, cars)
  - 🟠 **Orange** – Equipment & packages (boxes, pallets)
  - 🟡 **Yellow** – Safety gear & cones
  - 🟣 **Purple** – All other detected objects
- **Live info panel** – FPS, frame count, detection count, model ID, controls.
- **Screenshot saving** – Press `s` at any time.
- **Graceful error handling** – API failures and camera disconnects are logged without crashing.

## Architecture

```
Main Thread
│
├─ cap.read()          → capture frame at 30 FPS
├─ draw_detections()   → overlay latest bounding boxes
├─ draw_info_panel()   → overlay performance stats
├─ cv2.imshow()        → display annotated frame
└─ waitKey(1)          → handle keyboard input
       │
       └── every 0.5 s → spawn Background Thread
                           detect_objects_async()
                           │  encode frame → JPEG → base64
                           │  POST to Roboflow API
                           │  parse predictions
                           └─ update self.detections (thread-safe lock)
```

## Choosing a Model

The default model (`coco/17` – COCO YOLOv8) detects 80 common object classes including people, cars, and boxes. For higher accuracy on warehouse-specific objects (forklifts, pallets, hard-hats), train a custom model on Roboflow Universe.

Set `MODEL_ID` in `.env` to your custom model slug:

```
MODEL_ID=my-org/warehouse-detector/4
```

## Troubleshooting

### Camera won't open
- Ensure no other application is using the webcam.
- Try `CAMERA_SOURCE=1` if `0` doesn't work.
- On Linux, check `/dev/video*` devices.

### API errors (401 Unauthorized)
- Verify `ROBOFLOW_API_KEY` in `.env` is correct and has not expired.

### No detections appearing
- Lower `CONFIDENCE_THRESHOLD` to `0.3`.
- Ensure good lighting and that objects are in frame.
- Check the terminal for `⚠️` error messages.

### Video window freezes
- This should not happen by design. If it does, ensure Python ≥ 3.11 and OpenCV ≥ 4.8.

## Robot Integration

To adapt this system for a physical robot:

1. Set `CAMERA_SOURCE` to the robot's RTSP feed URL.
2. Read `detector.detections` after each cycle.
3. Implement safety logic, e.g.:
   ```python
   persons = [d for d in detector.detections if d["class"] == "person"]
   if persons:
       robot.emergency_stop()
   ```
4. Add obstacle-avoidance commands based on bounding-box positions relative to frame centre.
